Adaptive finite-PCG checkpoint selection
========================================

Version         : 3.4.0
Fine grid       : h=1/128
Coarse grid     : H=1/16
Contrast        : 1e+04
Smoother        : one forward + one backward Gauss-Seidel
Solve tolerance : 1e-6
Timing          : one end-to-end run per candidate
Selector        : midpoint adaptive screen

Note: The selector evaluates the geometric basis, a minimum-step anchor and an interval midpoint. At most one midpoint refinement is added from the pilot forecast and normalized PCG energy residual; no full confirmation solve is used during setup.
