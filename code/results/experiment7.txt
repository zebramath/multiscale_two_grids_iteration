Adaptive finite-PCG checkpoint selection
========================================

Version         : 3.2.0
Fine grid       : h=1/128
Coarse grid     : H=1/16
Contrast        : 1e+04
Smoother        : one forward + one backward Gauss-Seidel
Solve tolerance : 1e-6
Timing          : one end-to-end run per candidate
Selector        : cost-aware sparse screen

Note: The v3.2 selector pilots the geometric basis and at most two positive PCG checkpoints on this large grid (m=16 and m=40). It does not run finalists to the solve tolerance during selection. The selected candidate is evaluated independently in the end-to-end table, so forecast error is not hidden in the reported cycle count. The staged row uses the v3.1 quality policy with the v3.2 hierarchy-reuse fix.
