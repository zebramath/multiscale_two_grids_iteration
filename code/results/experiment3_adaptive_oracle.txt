Adaptive finite-PCG checkpoint selection
========================================

Version         : 3.7.0
Fine grid       : h=1/128
Coarse grid     : H=1/16
Contrast        : 1e+04
Smoother        : one forward + one backward Gauss-Seidel
Solve tolerance : 1e-6
Timing          : one end-to-end run per candidate
Selector        : midpoint adaptive screen

Note: The selector evaluates the geometric basis, a minimum-step anchor and an interval midpoint. If the midpoint remains hard, its normalized PCG energy residual chooses one interior or forward checkpoint. No full confirmation solve is used during setup, and the selected hierarchy is reused.
