# multiscale_two_grids_iteration v6.3

二维高对比扩散问题中，有限 Krylov 能量插值与两网格非单调收敛研究。

- `research_report.md`：研究问题、理论主线、算法设计与完整核心结果；
- `theory.tex`：能量路径、粗空间几何、非单调机制和尺度自适应选择理论；
- `VALIDATION_v6.3.md`：严格构建、数值回归、理论公式与文稿静态验证记录；
- `code/`：C++17 两网格实现、六个整合实验、测试和 TXT 结果。

理论稿使用 `ctexart`，需以 XeLaTeX 配合 TeX Live 中文组件编译。

算法使用分辨率归一化的路径位置，根据粗空间分辨率和矩阵对角尺度比构造一个有限
PCG 插值，只进行一次路径推进、插值组装和粗算子构造。

理论主线包括任意区间 PCG 精确能量尾和、图空间闭式正交补、能量误差与两网格性能的
双向定量传递，以及重主导奇异值下仅依赖粗响应满秩的有利方向充要条件。理论稿进一步
求解固定插值能量预算下的局部最优问题，给出尖锐 Pareto 常数、唯一能量归一最优方向
和秩亏时的一阶失效，并把严格反单调尾部推广到渐近相干 PCG 路径。步数选择仍由条件性
$\Theta(h^{-1})$ 双侧窗口支撑。

完整结果覆盖尺寸、三个对比度、六类系数拓扑、两组 256/16 大尺度问题、五种 seed、
六类 RHS 迁移和中心 128/16 问题的重复计时；oracle 选择质量按七个设计问题与三个
参数冻结后的新组合分别报告。

v6.3 新增两项投稿导向验证：六个代表问题上的停止策略消融，将 adaptive 与统一
`m=round((1/h)/4)` 及逐列相对残量 `1e-2` 比较；三层嵌套网格加密固定连续坐标中的
通道宽度、背景分区与 seed，并逐个共享节点核验系数一致。原四份正式结果保持 v6.2
归档数值，不作无必要的重复运行；两份新增结果由 6.3.0 源码生成。
