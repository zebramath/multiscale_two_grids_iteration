# Changelog

## 2.7.0

- 统一将五个数值程序、构建目标和结果文件命名为 `experiment1` 至 `experiment5`。
- 将实验支持层拆分为配置、问题工厂、候选、评估和报告模块。
- 从全部数值输出中移除残差指标。
- 增加 `P nnz`、`L nnz` 和显式 `Converged`，使结构成本与收敛状态完整可审计。
- 用实际求解的平均收敛因子替代每个候选额外 80 步谱幂迭代，减少实验开销。
- 统一问题装配入口，保证每个系数场在单个实验中只装配一次。
- Release 构建默认尝试启用 IPO/LTO；仍保留可移植的关闭选项。
- 新增一键构建、测试和顺序运行脚本。
- 保留 v2.6 的默认 `128/16` 网格、三种系数场、固定随机种子和 40000 次安全上限。
