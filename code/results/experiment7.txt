Adaptive finite-PCG checkpoint selection
========================================

Version         : 3.1.0
Fine grid       : h=1/128
Coarse grid     : H=1/16
Contrast        : 1e+04
Smoother        : one forward + one backward Gauss-Seidel
Solve tolerance : 1e-6
Timing          : one end-to-end run per candidate
Selector        : screen-refine-confirm

Note: The selector first screens coarse PCG checkpoints with 32 cycles, backtracks from the best screen anchor, refines at spacing two with 64-cycle pilots, and continues only two diverse finalists to the actual solve tolerance. The final objective is measured cycles on the representative right-hand side.
