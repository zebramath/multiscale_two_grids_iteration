# multiscale_two_grids_iteration v5.3

二维高对比扩散问题中，有限 Krylov 能量插值与两网格非单调收敛研究。

- `research_report.md`：研究问题、理论主线、算法设计与完整核心结果；
- `theory.tex`：能量路径、粗空间几何、非单调机制和尺度自适应选择理论；
- `VALIDATION_v5.3.md`：严格构建、回归、Sanitizer 与完整实验记录；
- `code/`：C++17 两网格实现、四个整合实验、测试和 TXT 结果。

算法使用分辨率归一化的路径位置。fast 根据粗空间分辨率和矩阵对角尺度比只构造一个
候选，不运行 pilot；reuse 在 `(1/h)/8` 到 `(1/h)/2` 上检查固定五点，并用短两网格
残量轨迹选择。两档分别服务于低 setup 的少 RHS 场景和可摊销 setup 的多 RHS 场景。

理论稿给出最优步数尺度分析：Jacobi--PCG 条件数满足标准 $h^{-2}$ 伸缩时，固定能量
衰减所需步数为 $O(h^{-1})$；在相关谱分量非退化和最优点位于固定可见误差带的条件下，
得到 $c_-h^{-1}\le m_{\mathrm{opt}}(h)\le c_+h^{-1}$。固定归一化候选的离散损失进一步
由候选覆盖半径控制；离线 sampled oracle 输出 $m_{\mathrm{or}}/(1/h)$ 检验该尺度窗口。

完整结果覆盖尺寸、三个对比度、六类系数拓扑、两组 256/16 大尺度问题、五种 seed、
六类 RHS 迁移和中心 128/16 问题的重复计时；oracle 选择质量按七个设计问题与三个
参数冻结后的新组合分别报告。
