# multiscale_two_grids_iteration v7.3

二维高对比扩散问题中，有限 Krylov 能量插值与两网格非单调收敛研究。

- `research_report.md`：研究问题、理论主线、算法设计与完整核心结果；
- `theory.tex`：能量路径、粗空间几何、非单调机制和尺度自适应选择理论；
- `VALIDATION_v7.3.md`：本轮定位修订、严格构建与文稿静态验证记录；
- `code/`：C++17 两网格/三层 V-cycle 实现、七个整合实验和对应 TXT 结果。

理论稿使用 `ctexart`，需以 XeLaTeX 配合 TeX Live 中文组件编译。代码采用 C++17，
可直接运行 `code/scripts/run_validation.sh quick` 完成严格构建与小规模端到端检查。

adaptive 的明确定位是

$$
\boxed{\text{theory-informed lightweight empirical selector}}.
$$

它使用分辨率归一化的路径位置，根据粗空间分辨率和矩阵对角尺度比构造一个有限
PCG 插值，只进行一次路径推进、插值组装和粗算子构造。理论只支持固定能量衰减所需的
$m=O(h^{-1})$ 步数尺度；$1/8,1/4,1/3,1/2$ 和 $10^3,10^5$ 均为当前问题族上的经验
参数，不宣称最优或 near-oracle。

理论主线包括任意区间 PCG 精确能量尾和、图空间闭式正交补、能量误差与两网格性能的
双向定量传递，以及重主导奇异值下仅依赖粗响应满秩的有利方向充要条件。理论稿进一步
求解固定插值能量预算下的局部最优问题，给出尖锐 Pareto 常数、唯一能量归一最优方向
和秩亏时的一阶失效，并给出可沿有限 PCG 路径逐步核验的严格反单调充分条件。
$O(h^{-1})$ 的充分尺度不被解释为两网格最优步数定理。

完整证据覆盖尺寸、三个对比度、六类系数拓扑、两组 256/16 大尺度问题、五种 seed、
六类 RHS、中心问题重复计时、停止策略消融与固定物理几何嵌套加密。三层 V-cycle
实验在 64/16/8 与 128/16/8 层次上逐级构造 Galerkin 算子，并将首层精确两网格与
递归粗解配对，同时报告算子复杂度和插值复杂度。它是机制可递归性的补充证据，不承担
任意层数最优复杂度主张。
