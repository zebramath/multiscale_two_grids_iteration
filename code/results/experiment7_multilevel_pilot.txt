Three-level V-cycle feasibility study
=====================================

Mode            : full
Cases           : 2
Hierarchy       : 64/16/8, 128/16/8
Contrast        : 1e4
Smoother        : 1 forward + 1 backward Gauss-Seidel
Coarsest solve  : exact sparse Cholesky
Threads         : 4
Solve tolerance : 1e-6

Note: The same interpolation construction is applied independently on both Galerkin transitions. Exact two-grid cycles using the first transfer provide the controlled reference for replacing the exact coarse solve by one recursive V-cycle. This experiment is a feasibility check; the proved results remain two-grid statements.
