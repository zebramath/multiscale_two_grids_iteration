# Changelog

## 2.2.0

- 新增逐轮残差预算支撑扩展，包含三种强连接归一化。
- 新增 `K=128` 扩展后按基幅值压缩到约 `K=64` 并重新能量极小化。
- 固定预算实验改用选择性温启动重求解，避免未变化列重复 PCG。
- 新增实验 5：支撑算法消融、分阶段计时和 CSV 输出。
- 新增实验 6：六个右端项、失败数、平均/最坏循环数和能量谱代理。
- 新增实验 7：可配置种子、对比度、网格规模和 `H/h` 扫描。
- 新增随机频谱制造解和点源右端项。
- 修正误差传播谱代理，改为 A-范数收缩率的幂迭代估计。
- 新增小规模自动测试、CTest 集成和快速/完整研究套件脚本。
- 版本更新至 2.2.0。
