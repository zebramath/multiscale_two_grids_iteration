# multiscale_two_grids_iteration v7.4

本项目研究二维高对比扩散问题中的有限 Krylov 能量插值。核心发现是：沿 PCG 路径，
插值能量单调下降并不保证固定磨光器下的两网格性能单调改善；在所测试的问题中，适当的
有限步插值可以同时降低构造成本和总求解成本。

## 方法定位

adaptive 方法定位为

$$
\boxed{\text{theory-informed lightweight empirical selector}}.
$$

理论在条件数假设 $\kappa_h=O(h^{-2})$ 下，只支持把能量误差降低到固定比例所需的
$m=O(h^{-1})$ 充分步数尺度。在线规则使用的归一化位置
$1/8,1/4,1/3,1/2$ 和对角尺度比阈值 $10^3,10^5$ 均为经验参数，不宣称最优或
near-oracle。该规则只构造一个候选，并且只进行一次 PCG 路径推进、插值组装和粗算子
构造。

## 主要结论与边界

- 理论建立了 PCG 能量账本、归一化误差的粗空间几何、对称两网格投影表达式，以及
  能量误差与两网格性能之间的双向定量联系。
- 局部理论给出重主导奇异值下有利方向的充要条件、尖锐 Pareto 常数和有限 PCG 路径上
  可逐步核验的严格反单调充分条件。
- 七组实验覆盖尺度、对比度、六类通道拓扑、随机 seed、不同右端项、重复计时、停止
  策略消融、固定物理系数场加密和三层 V-cycle 可行性。
- 结论限于当前二维离散、固定粗点和指定磨光器设置；三层实验不构成任意层数的网格
  无关收敛或线性复杂度证明。

## 文件结构

| 文件或目录 | 内容 |

| `research_report.md` | 可直接用于汇报或论文初稿的研究定位、理论摘要、实验口径与完整结果 |

```bash
cd code
./scripts/run_validation.sh quick
```

v7.4 只修改理论边界、说明文字和输出文案，数值算法、实验参数及正式结果均未改变。
