Adaptive finite-PCG checkpoint selection
========================================

Version         : 3.3.0
Fine grid       : h=1/128
Coarse grid     : H=1/16
Contrast        : 1e+04
Smoother        : one forward + one backward Gauss-Seidel
Solve tolerance : 1e-6
Timing          : one end-to-end run per candidate
Selector        : cost-aware sparse screen

Note: The v3.3 selector fits a robust tail model at the geometric basis and one anchor, projects a data-dependent third checkpoint when needed, and never confirms a candidate to the solve tolerance during setup.
