# multiscale_two_grids_iteration v4.0

二维高对比扩散问题的能量插值、有限步全局 PCG 与两网格收敛研究。

- `research_report.md`：当前项目的研究定位、算法实现和全部核心数值结果。
- `theory.tex`：有限 Krylov 正则化、两网格非单调性和多层递推分析。
- `VALIDATION_v4.0.md`：严格编译、单元/回归测试、UBSan 和四组完整实验记录。
- `code/`：C++17 两网格/多层实现、4 个整合实验、测试和完整 TXT 结果。

v4.0 将实验主线收束为自适应有限 PCG 与全局能量极小插值在不同尺寸、对比度和
系数拓扑下的受控比较。新增递归 Galerkin 多层 V-cycle，并同时作为独立迭代和
共轭梯度预条件子验证；低价值的独立诊断、参数消融和压力测试入口已删除或合并。
