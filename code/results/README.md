# v3.3 数值结果

本目录中的 experiment1--7、9--14 均由 v3.3.0 源码在同一次最终验证阶段重新生成。CSV 用于统计，TXT 为可读报告。

主要结果：

- 原始 `128/16` 交叉通道：自适应选择 `m=40`，234次循环；步长2 oracle 为 `m=38`、231次。
- 18问题矩阵：自适应总循环数1875，固定 `m=40` 为2586；18个自适应候选全部收敛。
- 六问题步长2 oracle：平均 gap 8.33%，最大14.00%。
- 八问题诊断集：平均 gap 3.04%，最大12.05%。
- 八问题压力集：平均 gap 4.63%，最大28.10%。
- 五右端项实验中，相对几何插值的 break-even 均为1个 RHS；相对固定 `m=40` 为3、4、3和66个 RHS。

墙钟时间来自单机单次测量，适合同机相对比较，不适合跨机器比较绝对值。
